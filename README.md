# 🍔 Salt'n Pepper Restaurant Website Clone

Welcome to my first complete frontend project! This is a pixel-perfect clone of the **Salt'n Pepper Restaurant** homepage layout, built entirely from scratch. I developed this project to transition from theoretical learning into practical, real-world frontend development.

## 🚀 Live Demo
See the website live in action here: 
👉 **[View Live Project](https://afsheen-kanwal.github.io/salt-n-pepper-website/)**

## 🛠️ Tech Stack & Skills Used
*   **HTML5:** Structured semantic elements (`<header>`, `<nav>`, `<section>`, `<footer>`) to keep code clean and accessible.
*   **CSS3:** Styled custom elements, managed font hierarchies, implemented precise color matching, and designed layout containers.
*   **Layout Techniques:** Practiced absolute and relative positioning to recreate complex visual layers like the **Upto 50% Discount** sticker overlapping the banking grid banner.

---

## ✨ Features Implemented
*   **Top Navigation Bar:** Clean brand header with "Home", "About", and a prominent red "Order Online" call-to-action button.
*   **Promotional Campaign Grid:** A showcase section displaying active bank credit/debit card discounts (HBL, Silkbank, Allied Bank, MCB, etc.).
*   **Urgent Banner Alert:** A styled, full-width hot-green banner promoting "FREE DELIVERY" with integrated contact hotlines.
*   **Brand Ecosystem Showcase:** A dedicated segment highlighting distinct subsidiary branches like *Express*, *Village*, and the flagship *Restaurant* logos.

---

## 📈 Key Takeaways from this Practice
As an aspiring Frontend Developer, building this project independently helped me learn:
1. How to map out a visual layout mentally before starting to type code.
2. The importance of proper class naming conventions in CSS for easy maintenance.
3. How to bundle images and relative folder paths correctly so they don't break when deployed online.
4. Version control basics by pushing files directly to GitHub.
